# テキストエンドロール

![テキストエンドロール](https://github.com/user-attachments/assets/0527b93e-1caf-4961-973e-3ba98bb50819)

このプラグインは、AviUtl2 のテキストオブジェクトを**エンドロールのように流す**ための AviUtl2 用のプラグインです。

スタッフロールを書いたテキストオブジェクトにフィルタ効果として追加するだけで、画面の外から入って反対側へ抜けていくスクロールになります。

主に、
- テキストを**縦（下から上・上から下）にも、横（右から左・左から右）にも**流せる
- **どれだけ長いテキストでも途中で切れずに**最後まで流れる
- オブジェクトの長さを変えると**速度が自動で決まり**、速度を入れると**長さが自動で変わる**
- 画面の端で文字をなめらかに消す**フェード**

といった機能を提供します。

文字を描いているのは AviUtl2 本体なので、フォント・文字色・縁取り・行間などの見た目は、いつものテキストオブジェクトの設定がそのまま使えます。

## 動作環境

- AviUtl2 2.1.11 以上
- Windows 10 / 11（64bit）

## インストール

次のステップでインストールすることが可能です。

1. [Releases](https://github.com/Tksn07/aviutl2-endroll/releases) から最新の `text_endroll.aux2` をダウンロード
2. AviUtl2 の Plugin フォルダ（例: `C:\ProgramData\aviutl2\Plugin`）に入れる
3. AviUtl2 を起動し直す

# テキストエンドロールの使い方

基本的な使い方の説明を行います。

## 基本の使い方

### 1. テキストオブジェクトにスタッフロールを書く

まずはいつも通りテキストオブジェクトを置いて、流したい文章を書きます。

![テキストオブジェクト](https://github.com/user-attachments/assets/eaaa7625-0cc1-4a6f-86fd-5a4ca0b6fdc2)

```text
出演
山田 太郎
佐藤 花子

編集
鈴木 一郎

音楽
高橋 葵
```

フォントや文字の大きさ、文字揃えなども、好みの設定可能です

<br>

### 2. フィルタ効果「テキストエンドロール」を追加する

![テキストエンドロール](https://github.com/user-attachments/assets/58d8bb45-e227-4fbf-ab5f-ab55cdb3269e)

<br>

![テキストエンドロール追加](https://github.com/user-attachments/assets/50f74523-8b2f-4117-bb62-b729bdad9789)


テキストオブジェクトに、「加工 < テキストエンドロール」を追加します。

追加するとすぐに、テキストが画面の下から入って上へ抜けていくようになります。

<br>

### 3. オブジェクトの長さで流れる速さを決める

テキストは、**オブジェクトの先頭で画面の外から入り始め、オブジェクトの最後でちょうど反対側へ抜け切る**ように流れます。

そのため、オブジェクトを長くするとゆっくり、短くすると速く流れます。BGM の長さに合わせたい場合は、オブジェクトの長さを BGM に合わせるだけで大丈夫です。

流れ始める前や流れ終わったあとに間を空けたい場合は、オブジェクトを置く位置で調整してください。

<br>

## 設定項目

| 項目 | 初期値 | 説明 |
|---|---|---|
| 方向 | 下から上 | 流れる向きです。下から上・上から下・右から左・左から右から選べます |
| 速度(px/秒) | ー | 1秒あたりに流れる距離です。オブジェクトの長さと連動します（後述） |
| ブロックの区切り | 空行ごと | 横に流すときだけ表示されます（後述） |
| ブロックの間隔 | 150 | 横に流すときだけ表示されます。ブロックとブロックの間の幅です |
| フェード | 0 | 画面の端で文字を少しずつ消す幅です。縦に流すときは「上」「下」、横に流すときは「左」「右」が表示されます |

<br>

## 速度とオブジェクトの長さの連動

「速度(px/秒)」とオブジェクトの長さは、いつもお互いに合うように自動で調整されます。

| やったこと | 自動で変わるもの |
|---|---|
| オブジェクトの長さを変えた | 速度が、その長さでちょうど流し切れる値に変わります |
| 速度に数値を入れた | オブジェクトの長さが、その速度で流し切れる長さに変わります |
| テキストの内容や文字の大きさを変えた | 速度が、今の長さでちょうど流し切れる値に変わります |

「長さは決まっているので、それに合わせて流したい」ときはオブジェクトの長さを、「このくらいの速さで流したい」ときは速度を変えてください。

### 後ろに別のオブジェクトがあるとき

速度を入れてオブジェクトを伸ばそうとしたとき、すぐ後ろに別のオブジェクトがある場合は、**ぶつからないところまで伸ばして**、その長さで流し切れる速度に直します。

入れた数値より速度が大きくなって戻ってきたら、後ろのオブジェクトに当たって伸ばしきれなかった、ということです。

### テキストを編集しているとき

テキストを入力している途中は、入力の邪魔にならないように速度の書き換えを待ちます。

オブジェクトの選択を外すと、そのときの内容に合わせて速度が書き換わります。

<br>

## 縦に流す

「下から上」「上から下」を選ぶと、テキストを縦に流します。一般的なエンドロールの流れ方です。

- 横の位置は、オブジェクトの **X 座標**と、文字揃えの**左寄せ・中央揃え・右寄せ**で決まります
- 縦の位置（Y 座標）は使いません。Y 座標をずらしていても、必ず画面の外から入って反対側の外まで抜けます

### 長いテキストも最後まで流れます

AviUtl2 のテキストオブジェクトは、文章がとても長いと途中から下が表示されなくなります（文字の大きさ 45 で、300 行くらいが目安です）。

テキストエンドロールでは、長い文章でも**途中で切れずに最後の行まで流れます**。何百人ものお名前を並べるような長いエンドロールも、1つのテキストオブジェクトに書いて大丈夫です。

<br>

## 横に流す

「右から左」「左から右」を選ぶと、テキストを横に流します。

横に流すときは、テキストを**ブロック**というかたまりに分けて、横一列に並べて流します。分け方は「ブロックの区切り」で選べます。

### 空行ごと（エンドロール向け）

空行で区切られたかたまりが、1つのブロックになります。役職とお名前のかたまりが横に並んで流れていきます。

```text
出演            編集        音楽
山田 太郎       鈴木 一郎   高橋 葵
佐藤 花子
```

### 1行ごと（テロップ向け）

1行が1つのブロックになります。ニュースの速報のように、文章が1行ずつ横に流れていきます。

```text
本日もご覧いただきありがとうございました。   次回は来週の土曜日です。
```

### 横に流すときの位置

- ブロックは書いた順に並びます。「左から右」では、**最初に書いたブロックが最初に画面に入ってくる**ように並びます
- 縦の位置は、オブジェクトの **Y 座標**と、文字揃えの**上・中・下**で決まります
  - 上：Y 座標がブロックの上端になり、ブロックの上がそろいます
  - 中：Y 座標がブロックの中央になり、ブロックの中央がそろいます
  - 下：Y 座標がブロックの下端になり、ブロックの下がそろいます
- 横の位置（X 座標）は使いません。X 座標をずらしていても、必ず画面の外から入って反対側の外まで抜けます

<br>

## フェード

画面の端に近づいた文字を、少しずつ透明にして消すことができます。

「フェード」を開いて、文字を消していく幅を入れてください。0 のときはフェードしません。

- 縦に流すとき：「上」「下」で、画面の上の端・下の端の幅を決めます
- 横に流すとき：「左」「右」で、画面の左の端・右の端の幅を決めます

縦と横で別々の値になっています。方向を切り替えたときは、フェードの値も入れ直してください。

<br>

## ご注意

- **横に流すとき、1つのブロックがとても長いと途中で切れます。** 1行の文章がとても長い場合です（文字の大きさ 45 で、全角 360 文字くらいが目安です）。長い文章は、何行かに分けてください
- **横に流すとき、画面より背の高いブロックは上下がはみ出します。** お名前がたくさん続く場合は、途中に空行を入れてブロックを分けてください
- **途中で文字の大きさや色を変える制御文字は、うまく引き継がれないことがあります。** テキストを内部で分けて描いているためです
- **「文字毎に個別オブジェクト」には対応していません。** オンにしても、全体が1枚のテキストとして流れます
- **テキストの「表示速度」（1文字ずつ表示する設定）は、意図どおりに動きません。** テキストを内部で分けて描いているため、分けたかたまりごとに表示が始まります
- **テキストオブジェクト以外にも付けられますが、長さの上限があります。** 画像などに付けた場合はそのまま流しますが、とても大きな画像は途中で切れます
